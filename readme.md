# Library Management System

A simple console-based Library Management System built in Java.

## Features

- Add Books
- Search Books
- Issue Books
- Return Books
- Save Data to File
- Load Data from File

## Concepts Used

- Object Oriented Programming (OOP)
- ArrayList
- File Handling
- Exception Handling
- Java Collections

## How to Run

```bash
javac libraryManagement.java
java libraryManagement
